# Terminal

Read this when the reader should copy one shell command. No import.

```mdx
<Terminal command="gh stack sync --prune" title="Terminal" />
```

- `command`: required. One command the reader runs now.
- `title`: optional, default `Terminal`. Set it only when that label is wrong.
- `className`: optional

A session, command output, or more than one command stays in a fenced code block.
