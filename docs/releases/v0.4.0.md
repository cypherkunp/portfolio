# v0.4.0

Fourth tagged cut. `main` promoted onto `release`. This cut moves the site from Next.js to TanStack Start.

Tag: `v0.4.0`  
SHA: `7c9cb0b` (`refactor(ui): polish site surfaces and unify catalog styling`)

## Platform: TanStack Start

- `apps/www` is a TanStack Start app. Vite builds and serves it.
- Routes live in `apps/www/src/routes`. Every page is ported, including the Package Analyzer, Photos, Music, Inspirations, Bookmarks, About, and posts.
- Legacy URLs redirect to their new routes.
- Photo bytes are served from `GET /image`.
- Server functions are guarded by CSRF middleware, with tests.
- Dev tunnel support for local HTTPS through Cloudflare Tunnel (`pnpm dev:tunnel`).
- Next.js is removed. `next` is blocked by ESLint and by the `pnpm why next` check in CI.
- Links use `AppLink` from `@repo/ui/lib/app-link`. Images use `@/components/image`.
- Stack notes live in `docs/agents/stack.md`.

## Site

- Canonical host stays `www.devvrat.cc`. Document language is `en-GB`.
- Landing page is the visual source of truth (`.impeccable.md`).
- UI surfaces are polished and catalog styling is unified across apps.

## Design system

- `@repo/ui` owns primitives, layout, fonts, and tokens. `apps/www` imports them.
- Code blocks and MDX components match the landing page.

## Posts

- New posts on local HTTPS with Cloudflare Tunnel, Cursor hooks, software development philosophy, and calling a skill from a skill.
- An outdated post is removed.
- Blog skill and post template updated.

## Platform (tests and lint)

- Lint fails on warnings (`--max-warnings 0`).
- Lint and tests run after chat file edits.
- Unit tests (Vitest), Playwright e2e, and the `check` job (lint, `tsc`, `vite build`) run on pull requests to `release`.
